# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

结论为**不通过**的批次必须强制登记留样冷柜位：提交时柜位编号与预计取出日缺一不可，否则拒交（400）。顶栏「留样冷柜」进入专页，分在柜 / 超期留样 / 已取出三栏。取出日到期当天之后仍未点取出的批次自动进入超期栏，并自动记一条超期备忘（每批一条，幂等）。审评员可点取出、改取出日；观察员只能看冷柜与超期栏，不能登记、不能点取出。

这是制茶审评，不是菜谱，也不是饮食记录。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 不通过批次不填柜位编号或预计取出日，提交被拒（400）；两项齐全（如夏茶丙三项低分 + 柜位 B-07 + 取出日）才入库，并出现在冷柜在柜栏。
5. 在冷柜页把该批取出日改到昨天（不取出），刷新后该批进入超期留样栏，并在留样备忘中出现一条超期备忘；重复刷新不重复记。
6. observer 能打开留样冷柜页看到在柜与超期栏，但没有点取出 / 改期按钮，直接 POST 这些接口返回 403。
7. 审评员点取出后，批次从超期栏移到已取出栏。
