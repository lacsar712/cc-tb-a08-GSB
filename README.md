# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

结论**不通过**的批次强制登记留样冷柜：提交时必须填写柜位编号与预计取出日，缺一项拒交。顶栏「留样冷柜」专页分「在柜留样」与「超期留样」两栏；到期仍未点取出的批次自动进入超期栏并记一条超期备忘。审评员可改取出日、点取出；观察员只看冷柜与超期栏，不能登记、不能取出。

这是制茶审评，不是菜谱，也不是饮食记录。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 用偏低三项分提交「夏茶丙」并填柜位编号与预计取出日，提交成功并进入留样冷柜在柜栏；不通过却缺柜位或缺取出日时返回 400 拒交。
5. 在冷柜页把该批取出日改到昨天（不点取出），刷新后批次进入超期留样栏，并出现一条超期备忘。
6. observer 能打开留样冷柜页查看在柜与超期两栏，但没有改取出日/点取出按钮，直接 POST 后端返回 403。
